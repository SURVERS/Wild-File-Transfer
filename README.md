# Wild File Transfer

Wild File Transfer – это простой и быстрый способ передавать файлы, текст и медиа между устройствами в одной сети без облаков и посредников. Просто откройте страницу, нажмите «Получить», отсканируйте QR-код или перейдите по ссылке, затем добавьте файлы/текст и отправьте.

## Возможности
- Локальная генерация QR-кода с ссылкой на текущую сессию для приема
- Отправка файлов и текста в рамках одной сессии
- Автоматическая публикация загруженных файлов и текстов через REST API на сервере
- Одновременная работа с несколькими устройствами: просмотрите доступные файлы и скачайте их сразу после загрузки

## Запуск
1. Убедитесь, что установлен Go 1.25 или новее.
2. Запустите `start-transfer.bat` в корне проекта — он поднимет сервер и откроет главную страницу.
3. На приёмном устройстве нажмите «Получить» и отсканируйте QR-код или введите ссылку вручную.
4. На отправляющем устройстве выберите файлы/текст и нажмите «Отправить» — получатель увидит ссылки сразу.

## Структура
- `backend/` — Go-сервер, который генерирует QR, принимает файлы и отдаёт их по ссылкам.
- `frontend/` — HTML/CSS/JS с интерфейсом, загрузкой файлов, отображением QR-кода и ссылок на файлы.
- `start-transfer.bat` — скрипт запуска сервера и открытия браузера.

## Требования
- Go 1.25+
- Современный браузер с поддержкой Fetch и Drag&Drop

## Примечание
Сервер сохраняет файлы в `backend/uploads/{sessionId}`, а файл доступен по `http://<ваш-IP>:8080/files/{sessionId}/{имя}`. После завершения сессии можно просто удалить папку uploads.
